# Skin Composition

Build a character's appearance from independent clothing, hats, accessories and team details over a fixed base.

- Add, fully replace or hide selected character parts in a defined order.
- Apply the whole outfit together; an invalid outfit leaves the previous appearance intact.
- Keep the current animation, pose and pause state when changing items.
- Restore hidden parts according to the current animation.
- Validate items against every animation and inspect which parts each skin contains.
- Keep outfits independent for characters sharing the same artwork.

Cosmetic changes support regular image attachments. Base parts containing meshes, attachment points or collision shapes remain protected. Hiding affects a whole part, and changing the base ends the current composition.

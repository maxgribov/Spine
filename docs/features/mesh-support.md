# Mesh Support

Mesh characters are available on iOS and macOS, alongside ordinary SpriteKit content.

- Support ordinary, weighted and linked meshes with deformation animations.
- Preserve colors, transparency and drawing order as characters move.
- Combine mesh artwork with regular images, attachment points and static collision shapes.
- Share character artwork while keeping each character's animation and skin independent.
- Retain compatible deformation when changing skins.

Existing basic characters continue to work. Advanced rig constraints, clipping and animation mixing are outside current support.
